I wanted to get away from Spotify.
I ended up with a distributed system.

I run a home server that fetches lyrics, builds mood playlists, scores karaoke, generates cover art, and charts drum songs with models I trained myself. The queue and GPU infrastructure underneath grew because the music kept asking for more. A lot of it was built by directing AI coding agents. The harnesses, the checks, and the taste are mine.

AI engineering

The Agent Workshop

After my local-model assistants proved a consumer GPU could carry real jobs, I built co-hog — a coding agent on my own 12 GB card, so not every task leans on paid frontier tokens. Its harness taught me more than its model: when an agent fails, check the harness first. The bigger campaigns, like porting five Minecraft mods, I ran by directing frontier agents — and every novel failure became a reusable diagnostic skill.

The Story

How a playlist-cover generator became a distributed system

It started with Navidrome — my own Spotify. Then I missed the playlists and the lyrics, so I built lyric fetching, transcription, and mood analysis. The mood playlists wanted AI covers, and the image models lived on another machine's GPU, so I built a job queue. Then voices wanted the queue. Then video, 3D meshes, and a coding agent — until the copies collapsed into one lease engine on an event-sourced Postgres log. All because I wanted better music nights.
